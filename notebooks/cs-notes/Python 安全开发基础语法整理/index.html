2. 基础语法

2.1 编码规则

  • Python 3 默认使用 UTF-8 编码，一般不需要额外声明。
  • 文件开头可写：# -*- coding: utf-8 -*-，但 Python 3 通常可省略。

2.2 注释

  • 快捷键：Ctrl + / 可批量注释/取消注释。

2.3 缩进规范

  • Python 用缩进表示代码块，推荐 4 个空格。
  • 不要混用 Tab 和空格。

2.4 变量

  • 变量不需要声明类型，直接赋值即可。
  • 变量名建议小写，多个单词用下划线：scan_result。

2.5 多行语句

  • 用括号 ()、[]、{} 可以自然换行。
  • 用反斜杠 \ 也可以换行，但不推荐。

3. 数据类型

类型 关键字 示例 特点
整数 int 42 任意大小
浮点数 float 3.14 小数
复数 complex 1+2j 科学计算
字符串 str "hello" 不可变
三引号字符串 str """多行""" 保留格式
布尔 bool True / False 真/假
列表 list [1, "a", True] 可变、有序
元组 tuple (1, 2, 3) 不可变、有序
集合 set {1, 2, 3} 可变、无序、唯一
字典 dict {"name": "Alice"} 键值对
字节 bytes b"hello" 二进制
范围 range range(1, 6) 惰性序列

4. 可变与不可变

4.1 赋值逻辑

  • 列表、字典、集合是可变的，赋值是引用赋值（浅拷贝）。
  • 元组、字符串、数字是不可变的，修改会报错。

4.2 深拷贝与浅拷贝

  • 浅拷贝：.copy()、list()、dict()。
  • 深拷贝：copy.deepcopy()。

8. 面向对象编程

8.1 类与对象

  • 类：设计蓝图、概念。
  • 对象：类的实体化。
  • self 代表对象本身，定义方法时必须带上。
  • __init__ 是初始化方法，创建实例时自动调用。

8.2 Python 里所有东西都是对象

  • 函数可以赋值给变量、作为参数、作为返回值。

9. 推导式

10. 作用域

  • 就近原则：Local → Enclosing → Global → Built-in。
  • 修改全局变量用 global，修改外层函数变量用 nonlocal。

11. 闭包

  • 外层函数返回内层函数。
  • 内层函数调用外层函数的变量。
  • 内层函数记住外层作用域的变量。

14. 生成器

  • 特殊迭代器，惰性求值，用到哪读到哪。
  • 适合大文件读取、无限序列、大规模爬虫。

15. 装饰器

  • 在不修改原函数代码的情况下，增加功能。
  • 本质：func = decorator(func)。

19. 安全开发思维提示

思维 说明
不要信任用户输入 所有 input() 都要 .strip().lower() 清洗
路径要相对脚本目录 用 os.path.dirname(os.path.abspath(__file__)) + os.path.join
异常处理 文件不存在、网络超时、用户 Ctrl+C 都要捕获
边扫边写 循环中用 "a" 追加，防止中途崩溃丢数据
正则提取 用 re.search / re.findall 解析返回包、提取 IP
函数职责单一 一个函数只做一件事，方便复用和调试
先跑最小版本 每写一个函数就跑一次，不要一口气写完
先抄再改 先理解源码，照着敲，再闭卷写，最后改功能

进阶下

迭代

类似于遍历

迭代分两种类型1.for，2.迭代器

for(列表，元组，字典)迭代

比如说一个列表web，想批量加https://协议

那就for i in web:

迭代变量i相当于列表中的每一项元素

i = 'https://' + i

字典迭代

对象可以定义自己的一个方法，比如一个汽车的类，可以定义它的启动方法和停止方法。

字典是一个对象，也有它的一个方法

for key in data.keys()

两个括弧是调用，上面是对keys键进行了遍历

比如改成data.values()对值遍历

或者改成 for key,value in data.items()

（item是直接输出里面的键和值）

若直接遍历字典则遍历的是它的key

索引遍历

inenumerate(列表名) 可以自动打出索引值

如果括号包裹的话，前面也要加括号，要不然会报错（不知道为啥）

迭代器

iter()可以转化为迭代器，能通过next()进行调用，类似于for循环

生成器*

特殊的迭代器，能用到哪读到哪，惰性求值，用完就没了

场景：对于大文件读取，无限序列什么的。大规模爬虫，txt，如果一下全加载会卡，但是用生成器能提高效率

两种形式

生成器函数：

yield关键字（类似能逐步返回，能记录，能状态记忆的return）

函数接受一个值，yield很重要，有一个暂停的状态，有记忆功能，能记录遍历的状态

取得时候print(next(gen))，一个一个取，要用的时候再调用

实际使用：可以一批一批地读取数据，减少负载

生成器表达式：（类似于列表推导式）

用的不是很多，两个关键字，any和all就是或和与

常用any，只要判断出一个就不会再往后判断了

装饰器

回忆函数三个特性

如果想便捷的获取某个函数的执行时间

有弊端，如果想检测很多个函数，每个都要time.time()然后time-time，很麻烦

注意到函数能返回，函数能传参

定义一个新函数，传一个函数进去，在里面调用它，然后算出时间再返回

但是这个时候有个问题，如果这个函数本身有参数，那就不能传进计时函数中了

这个时候可以升级！使用闭包（闭包，在外部函数能传进来个参数，内部函数也能传，甚至能传关键字参数和位置参数）

这个时候还能升级！使用装饰器！在不影响程序本身代码的情况下，自动把函数传进这个装饰器函数中，然后对自身进行替换

比如用find_time()装饰func()，装饰器就相当于main()中func=find_time(func)

使用方式：@函数名

也有第三方装饰器可以下载

上下文管理器

with open不需要手动关闭
如果想自定义，可以用装饰器
