Linux基础常用命令

版本一：一般正常版（系统学习手册）

1. 文件系统管理

  • ls：查看当前目录内容
    • ls -l：查看详细信息（权限、大小、修改时间等）
    • ls -a：显示隐藏文件（以 . 开头的文件）
  • cd：切换目录
    • 绝对路径（如 cd /mnt/d）可跳到任意位置
    • 相对路径（如 cd game）访问当前目录下的子目录
    • cd 或 cd ~：回到用户家目录（/home/用户名）
    • cd ..：返回上一级目录
  • mkdir：创建目录
    • mkdir project：当前目录下创建 project
    • mkdir -p project/20260724/data：递归创建嵌套目录
  • rm：删除（无回收站，谨慎使用）
    • rm file：删除文件
    • rm -r project：递归删除整个目录
    • -f 参数强制删除（不询问），慎用 sudo rm -rf /*
  • mv：移动或重命名
    • mv file /path：将文件移动到目标路径
    • mv file1 file2：重命名 file1 为 file2
  • cp：复制（原文件保留）
    • cp file /path：复制文件到目标路径
    • cp -rf project /path：递归强制复制整个目录
  • pwd：显示当前工作目录的绝对路径

2. 文件查看与修改

  • cat：查看或拼接文件
    • cat file：输出全部内容（大文件慎用）
    • cat file1 file2 > file3：合并 file1 和 file2 到 file3
  • nano / vim：终端文本编辑器
    • 打开：vim file（不存在则新建）
    • vim 操作：按 i 进入插入模式，按 Esc 后输入 :wq 保存退出，:q! 不保存退出
    • nano：Ctrl+X，按 Y 确认保存，按 N 不保存
  • tail：查看文件尾部
    • tail file：默认显示最后 10 行
    • tail -n 20 file 或 tail -20 file：显示最后 20 行
    • tail -c n file：显示最后 n 个字节
    • tail -f / -F：动态追踪文件尾部变化（适合看日志）
  • less：分页查看大文件
    • less file，按 q 退出，按 h 查看快捷键帮助

3. 系统管理

  • kill：结束进程，需结合 ps 获取 PID
    • kill PID
  • top：实时进程监控（CPU、内存、负载等），直接输入 top 运行
  • ps：查看当前进程快照
    • ps aux：显示 CPU 和内存占用
    • ps -ef：显示进程树及父进程信息
  • uname：查看系统信息
    • uname -a：显示所有信息（操作系统、内核、架构等）
  • su：切换用户
    • su root：切换到 root，保留当前目录
    • su -：切换到 root 并加载其完整环境
  • sudo：提权执行命令（需在管理员组），如 sudo apt update

4. 网络相关

  • ping：测试网络连通性
    • ping baidu.com（Ctrl+C 停止）
    • ping -c 4 网址：发送 4 个包后自动停止
  • dig：DNS 查询工具
    • dig 网址：查询解析记录
    • dig +short 网址：直接显示 IP
    • dig -x IP：反向解析域名
  • nc（netcat）：网络连接工具，常用 nc IP 端口
  • ip：网络配置查看与设置
    • ip addr show：查看所有网络接口和 IP 地址
  • curl：命令行文件传输工具（支持多种协议）
    • curl baidu.com：返回网页 HTML 内容
  • wget：下载工具
    • wget 下载链接
    • wget -O /path/file 下载链接：指定保存路径和文件名

5. 备份压缩

  • zip：压缩
    • zip file.zip file1 file2 file3：压缩多个文件
    • zip -r data.zip /path/project：递归压缩目录
    • zip -e file.zip file：加密压缩（需输密码）
  • unzip：解压
    • unzip file.zip
    • unzip file.zip -d /path：指定解压目录
    • unzip -P password file.zip：解密解压（密码明文）
  • 7z：强大压缩/解压
    • 7z a file.7z file：压缩文件
    • 7z a file.7z -r /path：递归压缩目录
    • 7z a -ppassword file.7z file：加密压缩
    • 7z x 压缩文件：解压（支持多种格式）
  • gzip：压缩单个文件（生成 .gz，原文件删除）
    • gzip file.txt
  • gunzip：解压 .gz（删除 .gz，还原原文件）
    • gunzip file.txt.gz
  • tar：打包（不压缩）
    • tar -cf file1.tar /path：打包目录
    • tar -czf file1.tar.gz /path：打包并 gzip 压缩
  • unrar：解压 .rar
    • unrar x file.rar

6. 密码学工具

  • gpg：对称加密
    • gpg -c file：生成加密文件 file.gpg（原文件保留），解密 gpg file.gpg
  • openssl：加密/解密
    • 加密：openssl enc -aes-256-cbc -salt -in file -out file.enc
    • 解密：openssl enc -d -aes-256-cbc -in file.enc -out file

7. 软件与包管理（Debian/Ubuntu/Kali）

  • apt：包管理器
    • sudo apt update：更新软件源
    • sudo apt install <app>：安装软件

8. 其他常用命令

  • ssh：远程登录
    • ssh username@ip -p 端口号
  • env：查看或临时设置环境变量
    • env：查看所有环境变量
    • env 变量名=值 命令：临时设置并执行
  • source：执行脚本或激活配置文件
    • source file（无需执行权限）
  • chmod：修改文件权限
    • chmod +x 可执行文件：添加执行权限

自测

  • 第1题（要求：写出该指令的含义/作用）
    ls -la

    答案：查看当前目录下所有文件（包括以.开头的隐藏文件）的详细信息（权限、大小、修改时间等）。

    第2题（要求：写出对应的指令）
    如何一次性创建多层嵌套目录，例如在当前路径下创建 project/2026/data？

    答案：mkdir -p project/2026/data

    第3题（要求：写出该指令的含义/作用）
    cd ~

    答案：回到当前用户的家目录（即 /home/用户名）。

    第4题（要求：写出对应的指令）
    强制递归删除一个名为 old_backup 的文件夹，且系统不进行任何确认询问。

    答案：rm -rf old_backup

    第5题（要求：写出该指令的含义/作用）
    mv file1.txt file2.txt

    答案：将 file1.txt 重命名为 file2.txt。

    第6题（要求：写出对应的指令）
    将 log1.txt 和 log2.txt 的内容合并，写入到一个新文件 all.log 中。

    答案：cat log1.txt log2.txt > all.log

    第7题（要求：写出该指令的含义/作用）
    tail -f app.log

    答案：动态追踪（实时监控）app.log 文件尾部的日志变化（默认显示最后10行并持续更新）。

    第8题（要求：写出对应的指令）
    在 vim 编辑器中，不保存当前修改并强制退出编辑器。

    答案：先按 Esc 退出插入模式，然后输入 :q! 并回车。

    第9题（要求：写出该指令的含义/作用）
    ps aux

    答案：查看当前系统中所有运行进程的快照信息（包含 CPU 和内存占用率）。

    第10题（要求：写出对应的指令）
    切换到 root 用户，并同时切换当前工作目录到 /root，加载 root 的完整环境配置。

    答案：su -

    第11题（要求：写出该指令的含义/作用）
    ping -c 4 baidu.com

    答案：向 baidu.com 发送 4 个 ICMP 数据包来测试网络连通性，发包结束后自动停止。

    第12题（要求：写出对应的指令）
    直接查询并显示 github.com 这个域名解析后的 IP 地址（只显示IP，不显示其他DNS记录信息）。

    答案：dig +short github.com

    第13题（要求：写出该指令的含义/作用）
    wget -O /home/user/installer.tar.gz https://example.com/pkg.tar.gz

    答案：使用 wget 下载文件，并将下载的内容保存为 /home/user/installer.tar.gz（指定了保存路径和文件名）。

    第14题（要求：写出对应的指令）
    将 /var/www 整个目录打包，并使用 gzip 算法压缩，生成名为 www_backup.tar.gz 的压缩包。

    答案：tar -czf www_backup.tar.gz /var/www

    第15题（要求：写出该指令的含义/作用）
    unzip archive.zip -d /tmp/unpack

    答案：将 archive.zip 解压到指定的 /tmp/unpack 目录下。

    第16题（要求：写出对应的指令）
    使用 openssl 对明文文件 secret.txt 进行 AES-256-CBC 对称加密，并添加盐（salt），输出加密文件 secret.enc。

    答案：openssl enc -aes-256-cbc -salt -in secret.txt -out secret.enc

    第17题（要求：写出该指令的含义/作用）
    chmod +x startup.sh

    答案：给 startup.sh 脚本文件添加可执行权限。

    第18题（要求：写出对应的指令）
    通过 SSH 协议，使用用户名 admin 连接到远程主机 192.168.1.100 的 2222 端口。

    答案：ssh admin@192.168.1.100 -p 2222

    第19题（要求：写出该指令的含义/作用）
    sudo apt update

    答案：以超级管理员（root）权限，更新本地的 APT 软件包缓存列表（软件源信息）。

    第20题（要求：写出对应的指令）
    查看当前系统的主机名、内核版本、硬件架构等所有系统信息。

    答案：uname -a
