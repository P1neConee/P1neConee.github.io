3. 依赖链：为什么要按这个顺序学

Python 30天 → 其余三门
所有示例代码都是 Python；sklearn / PyTorch 的接口依赖函数参数、类继承、迭代器协议。
数据结构与算法 → 机器学习 / 深度学习
复杂度直觉决定你能不能处理大规模数据；图论对应计算图执行与依赖解析。
机器学习 → 深度学习
损失函数、梯度下降、过拟合与正则化会原样复现，只是模型从线性换成神经网络。
深度学习 → 元婴期（大模型安全）
Transformer 的 Q/K/V 是理解 Prompt 注入与越狱的前提；手搓 GPT 是拆开大模型的第一步。

6. 总自测 8 题

Q1. 四门课分别对应修仙路线的哪一阶段？
答：Python 30天与数据结构与算法 → 筑基期（练内力 / 算法筋骨）；机器学习 → 结丹期的机器学习基石；深度学习前 33 集 → 结丹期的深度学习基石，最后 3 集（Decoder-Only GPT）→ 已跨入元婴期入口。
Q2. 为什么 Python 要先于机器学习、深度学习？
答：因为 sklearn 的 fit/predict、PyTorch 的 nn.Module 继承与 Dataset 迭代器，全部是 Python 语法与面向对象；内力不够深，连示例代码都读不懂，更谈不上改。
Q3. 数据结构与算法在 AI 学习里是不是「面试专用、实战无用」？
答：不是。哈希表的 O(1) 决定 dict 为什么快；Top K 用堆而非全排序决定召回效率；图的拓扑排序就是计算图执行的顺序；「稠密 vs 稀疏」的取舍直接对应邻接矩阵与注意力的实现选择。
Q4. 机器学习里的「过拟合」在 AI 安全视角下意味着什么？
答：过拟合意味着模型记住了训练样本的细节。这正是成员推断攻击（判断某条数据是否在训练集中）与模型窃取能够奏效的根源——模型「背得太熟」反而泄露了隐私。
Q5. 梯度在机器学习和深度学习里分别扮演什么角色？安全视角下有何不同用法？
答：学习时：沿负梯度更新参数以降低损失。安全视角下（对抗攻击）：沿梯度方向给输入加微小扰动，让损失上升、模型判断翻转——FGSM 就是同一条梯度通路的正反两用。
Q6. 为什么 Transformer 被修仙文章称为「金丹大成的关键」？
答：因为 Prompt 注入、越狱、幻觉利用的直接作用对象就是大模型，而这些攻击之所以生效，根源在于自注意力的 Q/K/V 权重分配会被恶意指令劫持。不理解注意力，就看不懂越狱的底层逻辑。
Q7. Encoder-only / Decoder-only / Encoder-Decoder 怎么选型？
答：判断（分类、语义匹配）用 Encoder-only（BERT）；续写生成用 Decoder-only（GPT/Llama/Qwen）；转换（翻译、摘要）用 Encoder-Decoder（T5/原始 Transformer）。
Q8. 四门课走完，距离「能做 AI 安全研究」还差什么？
答：四门课解决的是「能看懂、能跑通、能对话」；还差元婴期对大模型本体（分词、嵌入、解码策略、对齐/RLHF）的拆解，以及化神、婴变期在真实攻防场景（越狱、注入、数据投毒、模型后门）中的实战。
