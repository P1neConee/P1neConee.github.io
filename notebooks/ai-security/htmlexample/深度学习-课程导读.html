模块 2 · 神经网络原理

第3-8集
修仙比喻：筑炉：感知机是火种，反向传播是鼓风，激活函数是灵魂。

核心知识点

  • 感知机：深度学习的 Hello World，单层只能解线性可分（异或即其死穴）
  • MLP 到神经网络的升级：多层 + 非线性 = 能拟合任意复杂函数
  • 反向传播：链式法则把误差从输出层层传回，让海量参数可训练
  • 激活函数为网络注入非线性：sigmoid/tanh 易梯度消失，ReLU 成为主流，输出层用 softmax
  • 梯度下降：模型自己寻找最优参数的引擎
  • 损失函数：定义「错了多少」，是训练的目标函数

模块 3 · 训练工程与调参

第9-14集
修仙比喻：控火：火候即调参，差之毫厘谬以千里。

核心知识点

  • 识别手写数字：别死磕 PyTorch 语法，先跑通全流程

  • 参数初始化：Xavier / Kaiming(He) 初始化，决定梯度能否健康流动
  • 归一化：BatchNorm / LayerNorm，Transformer 也用它稳定训练
  • 正则化：L1/L2、Dropout、权重衰减（AdamW 的关键）对抗过拟合
  • 优化器演进：SGD → Momentum → RMSProp → Adam / AdamW
  • 完整训练流程：数据 → 前向 → 损失 → 反向 → 更新 → 评估

模块 2 · 神经网络原理 （第3-8集）

第3集 感知机：深度学习的 Hello World BV1FW9ZBhEEN 转写 中

核心知识点

  1. 感知机是第一个真正落地的可学习机器方案（1957–1958 罗森布拉特），麻雀虽小五脏俱全，包含神经网络全部核心要素雏形：输入、权重、求和、激活、误差反馈、参数更新。
  2. 仿生与理论起源：1943 MP 神经元（阈值激活，输出 0/1）；1949 Hebb《行为的组织》提出权重可随"同时激活"增强（Hebbian learning）；1957 罗森布拉特加入"用错误反馈自动调整权重"使其真正可学习。
  3. 工作机制：加权求和 + 偏置 → 阶跃激活（≥0 输出 1，否则 0）；用 残差×学习率×输入 更新权重，多轮迭代收敛得到决策边界（线性可分）。
  4. 代码实现：NumPy 准备身高/体重数据 → 归一化到 0~1 → 定义 Perceptron 类 → 训练更新 W/bias → 绘制决策边界与误差曲线。
  5. 局限与转折：单层感知机只能解决线性可分问题；XOR（异或）线性不可分；1969 明斯基《Perceptrons》严密证明 → 神经网络 20 年寒冬；多层可解但当时无法训练，留待反向传播。
"感知机麻雀虽小五脏俱全，它完整地包含了神经网络所有的核心要素的雏形了。"—— 第3集《感知机：深度学习的 Hello World》· 转写校正版

第4集 深度学习架构：MLP到神经网络的升级，理解反向传播的基础 BV1XoRJB7ERe 转写 中

核心知识点

  1. 从单层感知机到 MLP：用两层感知机（含隐藏层）即可解决 XOR——第一层两个神经元分别学"至少一个为 1""不能同时为 1"（即 OR 与 NOT-AND 组合），输出层再 AND，等价于门电路堆叠。
  2. 仿生与数学依据：大脑皮层分层处理（底层响应边缘方向、高层响应人脸物体）；数学上任何复杂函数可由简单函数组合逼近（泰勒展开、傅里叶变换）。
  3. 全连接 MLP 结构：层间全连接，本质是函数的嵌套（上一层输出为下一层输入），同层多个神经元并行提取不同特征，多层逐级抽象。
  4. 为何必须非线性激活：多层线性变换组合仍为线性变换（W2·(W1X+B1)+B2 = W'X+B'），永远是一条直线；插入非线性（阶跃/ReLU/Sigmoid/Softmax）才能逼近复杂函数；1989 万能逼近定理：足够宽 MLP 可任意精度逼近任意连续函数。
  5. 寒冬症结：单层感知机学习规则只适用单层；只知道最终误差、不知隐藏层该调哪些权重——直到反向传播用链式法则逐层分配"责任"才解决。

第6集 激活函数：为神经网络注入灵魂 BV1RQL36cELq 转写 中

核心知识点

  1. 为何必须非线性：无激活则多层退化为单次线性变换（W'X+B'），永远一条直线；现实规律多为非线性。工程上先做线性（Wx+B，GPU/TPU 硬件加速、求导简单）再做独立非线性激活，并刻意选有界/温和导数的函数以抑制数值膨胀。
  2. 好激活函数的"基本素养"：非线性、处处可导（特殊点可规定）、梯度行为良好（不爆炸不消失）、计算廉价、最好零中心、单调平滑有界。
  3. 家族演进：阶跃（1958，不可导、信息损失大、无法训练多层）→ Sigmoid（1986，0~1 处处可导、适合二分类输出层，但导数最大 0.25 致梯度消失、非零中心、含指数计算贵）→ tanh（杨立昆 LeNet，输出 -1~1、导数最大 1、零中心减轻震荡，但本质仍 S 型两端饱和）→ ReLU（2010 辛顿/AlexNet，正半轴导数恒 1 缓解梯度消失、计算极快、稀疏激活自带正则，但有 Dying ReLU 死亡神经元、输出无上界）。
  4. ReLU 历史地位：让深层网络首次真正可训练，开启现代深度学习；平滑变体 Leaky ReLU / GeLU / SiLU 成为 Transformer 时代主流（GeLU 用于 BERT/GPT/ViT，SiLU 用于 LLaMA 系开源模型）。
  5. 选择指南：二分类输出用 Sigmoid、多分类用 Softmax；普通隐藏层资源有限用 ReLU，大模型精细训练用 GeLU/SiLU；激活函数提供非线性、梯度下降提供学习能力，二者配合训练网络。

第12集 归一化：Transformer 用了都说好的训练技巧 BV1X2Ex6rEu9 转写 中

  2. 标准化操作：减均值 ÷ 标准差（深度学习社区统称 normalization，实际是标准化），只做平移缩放、分布形状不变，让网络学模式而非绝对值，故不影响训练反而更稳。

第13集 过拟合的克星——正则化 BV1DHJ76SEmj 转写 中

核心知识点

  1. 过拟合/欠拟合/good fit 三态：训练损失持续下降、验证损失先降后升即过拟合；本质是模型容量超过任务所需复杂度，多余参数不去学数据背后规律，而是死记训练集噪声或个例。
  2. 正则化 = 奥卡姆剃刀原则的数学实现，强迫模型学习更简单、更通用的模式；广义上一切抗过拟合技术都算（狭义仅指 L1/L2 惩罚项）。
  3. L1 / L2：在损失后加权重惩罚项。L1（Lasso）倾向产生稀疏权重（近零比例 2.5%→22%，自动做特征选择、踢掉无用特征）；L2 倾向让所有权重均匀压小（近零比例 2.5%→3.8%，深度学习更常用，依赖神经元协同、处处可导对优化器友好）。
  4. 权重衰减 vs L2：标准 SGD 下二者数学等价；但 Adam 自适应缩放会把统一的 λ 扭曲（梯度小反而惩罚大），2017 年 AdamW 把权重衰减从自适应机制中独立出来，修复该 bug。
  5. Dropout（Hinton）：随机关闭部分神经元，强迫模型不依赖特定神经元、具隐式集成效果（每次不同子网络、推理≈集体投票）；Inverted Dropout 训练时放大保留神经元以保持期望一致；训练用 model.train()、推理用 model.eval()；隐藏层概率 0.5、输入层 0.1~0.2、Transformer <0.1、CNN 一般不用（用 BatchNorm）。
  6. Early Stopping：监控验证集，连续 5~20 epoch（patience）无改善即退回最佳 checkpoint 停，属隐式正则化、近乎零成本。

第16集 CNN 架构详解：卷积层、特征图、池化层 BV1NR7L6YEiF 转写 中

核心知识点

  1. CNN 整体架构：前段"特征提取器"（卷积层 → ReLU → 池化层 反复堆叠）+ 后段"分类器"（特征图展平 → 全连接 → Softmax）。
  2. 卷积层：用小矩阵（卷积核/滤波器）在图上滑动，逐窗口做对应位置相乘再求和，得到特征图（响应值 = 与卷积核模式的匹配程度）；无需展平、无需全连接，故参数量远少于 MLP。
  3. 卷积三要素：① 尺寸（3×3/5×5，越大视野大、参数多，现代多用 3×3）② 步幅 stride（默认 1，调大则特征图更小）③ padding（边缘补零以保持尺寸）。
  4. 输出尺寸公式：H_out = (H_in − K + 2P) / S + 1（例：32×32、K=3、P=1、S=1 → 32×32；S=2 → 16×16）。
  5. 多通道处理：卷积核维度 = 输入通道数（如 3×3×3），跨通道相乘求和再加偏置 → 一个卷积核只产出一张特征图；用多少个卷积核 = 输出多少个通道（特征图张数，与输入通道数无关）。
  6. 参数量优势：单层参数仅由卷积核决定（如 3×3×3×16 + 16 偏置 = 448），对比 MLP 动辄百万，差距巨大。

第18集 残差连接：让网络走向深度 BV1LGMw6HEEB 转写 中

核心知识点

  1. 深度重要性 + 退化问题：残差连接发明前网络被限 20 层左右；ResNet 论文对比 20 层 vs 56 层，56 层在训练/测试集上皆更差——此乃"网络退化"（两者皆差），不同于过拟合（训练好、测试差）。

第21集 RNN：模型开始理解自然语言序列 BV1FbNT6NEJL 转写 好

核心知识点

  1. 为什么 FNN/MLP 处理不了语言序列：①无法建模前后依赖（把词摊平一次性输入，丢失顺序；"银行"的含义依赖前文）②输入维度固定而句子变长，强行截断丢信息、padding 补位引入噪声。
  2. RNN 的核心思路：不改变词向量，改变"读句子的方式"——按时间步 t 从左到右逐 token 阅读，每步把当前输入 X_t 与上一步隐藏态 H_{t-1} 结合生成新隐藏态 H_t，直到 <EOS>；隐藏态是固定维度的浮点向量，是"对前面序列的有损摘要/记忆"，并非逐步对应某个词。
  3. 数学形式：H_t = tanh(ReLU)(W_x·X_t + W_h·H_{t-1} + b_h)；RNN cell 是同一个、参数共享（W_x/W_h/b_h 同步更新），因此参数量与句子长度解耦，可处理 10 个或 100 个 token，也天然支持不定长。
  4. 三类任务决定"何时输出"：整体分类（只用最后隐藏态接线性层+Softmax，如情感正负）序列标注（每个时间步的 hidden state 都接同一个任务头，如词性标注：代/副/动/名）序列生成（每步预测下一个 token，训练时把语料整体左移一位构造"输入—目标"，GPT 即此类）。
  5. 代码要点（PyTorch）：embedding 层（词表大小/embedding 维度）→ nn.RNN(input_size, hidden_size, batch_first=True) → 线性层输出 logits；训练用交叉熵损失（内部自带 Softmax，故训练时不手动 Softmax）+ 梯度下降，注意 padding 位置不计损失、生僻词用 <UNK> 兜底、句尾用 <EOS> 让模型学会停。
  6. 推理/生成策略：手工 Softmax 转概率后取 top-k；贪心（greedy）取概率最高，或通过 temperature / 在前 k 个中采样来增加多样性；`predict_next` 循环调用即构成 `generate`。
  7. RNN 的三大遗憾（也是后续模型的动机）：表示容量有限（全部历史压进固定维度，早期信息被后续乘法覆盖/弱化）、沿时间反向传播多次矩阵相乘导致梯度消失/爆炸（爆炸可控、消失难控）、本质是 while 循环/递归，前后依赖导致无法并行、训练效率低。改进路线：LSTM/GRU（门控，缓解长程依赖与梯度问题）→ Encoder-Decoder / seq2seq（输入输出不等长）→ Attention（回看全部隐藏态，缓解定长瓶颈）→ Transformer（自注意力 + 可并行）。

第22集 LSTM 与 GRU 改进 RNN 带来长期记忆 BV1ecKP6SELq 转写 好

核心知识点

  1. RNN 短记性的根因：H_t = tanh(W_x·X_t + W_h·H_{t-1} + b)，把 H_t 代入 H_{t+1} 后 W_h 被连续相乘（0.9 连乘 4 次已衰减到约 0.6，连乘 1000 次几乎归零）——前向传播早期信息被冲淡，反向传播则梯度消失（<1）或梯度爆炸（>1），训练极难。
  2. LSTM 的关键改动：除隐藏态 H_t 外新增细胞态 C_t（长期记忆，与主输出解耦），并用三个门做选择性读写——遗忘门 F_t（旧记忆保留多少）、输入门（候选记忆 \tilde{C}_t 写入多少）、输出门（暴露哪些记忆给 H_t）；门是 sigmoid 输出的 0~1 向量，逐维度连续控制比例（不是整体开关），由反向传播学出。
  3. 更新公式要点：C_t = F_t ⊙ C_{t-1} + I_t ⊙ \tilde{C}_t（按位相乘 element-wise），H_t = O_t ⊙ tanh(C_t)；加法路径是关键——与 ResNet 同构，让早期状态有"直通通道"，梯度不必反复连乘，显著减轻（非消除）梯度消失。
  4. GRU 是 LSTM 的简化：只有重置门 R_t（生成候选态时参考多少历史）和更新门 Z_t（旧状态与新候选各占多少），不再单独维护细胞态，H_t 兼任记忆与输出；H_t = Z_t ⊙ H_{t-1} + (1 − Z_t) ⊙ \tilde{H}_t（部分资料 Z_t 写法相反，等价）。参数更少、训练更快。
  5. 三者对比：参数量 RNN < GRU < LSTM；RNN 每步整体重写、效果最差；LSTM 控制最精细、长依赖最强但最慢；GRU 折中，数据量小或要求实时性时优选；纯 RNN 现已很少用。PyTorch 上层 API 几乎一致（nn.LSTM / nn.GRU，input_size、hidden_size、batch_first），只是 LSTM 前向传播返回 (h_n, c_n)、GRU 只返回 h_n。
  6. 实验佐证：口令回忆任务（8 种口令 + 大量干扰 token + 末尾 query），随机猜 12.5%；RNN 在长度 100~120 时只记住约 24%~26%，GRU/LSTM 接近 100%。
  7. 思想史联系：2015 年初 Highway Network 受 LSTM 门控启发（把"信息高速公路"搬进 FNN），2015 年底 ResNet 作为其特殊形式（默认让原信息全部通过、只学残差）胜出并统治深层网络。
  8. 局限与去向：仍是循环结构，H_t 依赖 H_{t-1} 故无法并行；门控只是缓解超长距离衰减；状态仍是固定维度瓶颈，无法直接访问更早表示 → 引出 attention（用时直接去查看，不必一路携带），Transformer 的 Self-Attention 进一步去掉时间步递推、实现并行。

第23集 编码器-解码器 与 seq2seq BV1Gk3G6pESk 转写 好

核心知识点

  1. 任务形态划分：RNN 擅长 sequence to one（读完整句用最后隐藏态分类：情感分析/新闻分类/垃圾邮件）与 sequence labeling / 序列标注（每个隐藏态接同一任务头，输入输出一一对应且同序：词性标注）；但机器翻译等属于 序列到序列——输入输出都是序列，且长度、语序、时间轴彼此独立（There's a cat under the table → 桌子下面有一只猫，语序与 token 数都不同），前两种都做不了。
  2. 史的两个节点：2014 年 6 月 Bengio 团队《RNN Encoder-Decoder》（同时提出 GRU）只是把 SMT（统计机器翻译）中的"短语匹配打分"换成神经网络编码的向量相似度，整体仍是统计机器翻译框架，Encoder-Decoder 只是辅助打分模块；2014 年 9 月 Google 的 Ilya Sutskever 等《Sequence to Sequence》才把整个句子端到端交给神经网络，去掉统计打分环节，编码器用四层 LSTM 读完整句得到 context vector，解码器逐词生成译文。
  3. 推理流程六步：编码器读完全部 token 得到上下文 → 用上下文初始化解码器隐藏态 S0 → 送入 BOS/SOS 开始符 → 逐步生成（I → like → …）→ 每步把自己的输出作为下一步输入，即自回归 → 遇到 <EOS> 或超过最大长度停止。
  4. 训练技巧一 Teacher Forcing：推理用自己上一步输出，训练则无论模型预测出什么都把真实标签作为下一步输入（把目标序列整体右移一位作解码器输入），否则一步错步步错、误差累积无法训练；注意损失仍按模型自己的错误预测计算，teacher forcing 只改变"下一步输入什么"，不改变损失函数。序列头尾处理：<BOS> + 目标 + <EOS>，解码器输入去掉尾部 <EOS>，监督目标去掉头部 <BOS>。
  5. 训练技巧二 源语句倒序输入（同为 Ilya 论文技巧）：让源句开头的词靠近解码起点，缩短源-目标 token 间的依赖路径，缓解 RNN/LSTM 记忆衰减（只是技巧，未解决循环依赖）。

第25集 注意力机制：大模型前夜的最后一块拼图 BV13UGu6yErd 转写 好

核心知识点

  1. 动机：seq2seq 把整句压成固定长度上下文向量（如 128/256 维），句子一长（乃至一部小说）信息损失严重；LSTM/GRU 只是缓解。类比人工翻译——不是先把原文背下来再凭记忆写，而是把原文放在手边边译边查。
  2. 核心改动：解码每一步不再只参考编码器最后一个隐藏态，而是对编码器全部隐藏态 H1…HN 按不同权重参考；输入序列的编码结果始终不变，变的是每个解码时间步算出的注意力权重与上下文向量（C3 ≠ C4），即"动态上下文向量"。
  3. 计算三步：①打分：用当前解码隐藏态 S_t 与每个编码器隐藏态做点积（相关性分数，可正可负、和不固定，需维度相同）②Softmax 归一化：把分数转成非负、和为 1 的注意力权重 ③加权求和得到动态上下文 C_t，再与解码器状态 S_t 拼接、做线性+非线性变换，最后经线性层与 Softmax 输出下一个 token 的概率。
  4. 实算示例（i love deep learning → 我喜欢深度学习）：解码到 S3 时打分显示最关注 deep（权重 0.78），得 C3 → 输出"深度"；到 S4 时最关注 learning → 输出"学习"；再下一步输出 <EOS>。
  5. *软对齐（soft alignment）**：不像统计机器翻译那样硬性规定 cat↔猫 一一对应，而是允许多个输入位置以不同权重同时参与；权重分配不是人为指定，而是为降低翻译误差由反向传播+梯度下降学出来的（可视化：译"下面"与 under 最相关、"猫"与 cat 最相关，即便"猫"在译文中位于末尾而原文在中间）。
  6. QKV 抽象：本质是可学习的信息检索——Q = 解码器状态 S_t（当前诉求）→ 与 K（编码器隐藏态，接受查询匹配）算分数 → Softmax 得权重 → 对 V（同样来自编码器隐藏态）加权求和。通用公式 Attention = Softmax(Q·Kᵀ/√d)·V（除以根号 d 为缩放点积，保数值稳定）。K 与 V 数值同源但作用不同，靠各自的可学习权重矩阵 W_K/W_V 做线性变换区分。
  7. 对照实验（用 and 拼接子句拉长句子，其余不变，仅解码器多约三行运算、参数增约 4.6%）：单子句两者均 100%；双子句无 attention 40.4%、有 attention 100%；三子句无 attention 几乎为 0、有 attention 97.5%。消融实验还证明：有了 attention 后，源句是否倒序输入结果一样（位置不再重要），而纯 seq2seq 倒序与否差别很大。
  8. 局限与通往 Transformer：attention 没有改动循环结构，仍需按时间步推进、训练慢。但 QKV 形式并不规定三者来源——若让 Q、K、V 都来自同一个序列（每个位置既发起查询、也接受匹配、也提供内容），就是自注意力 Self-Attention；此时各位置互不依赖，可一次性并行计算、吃满 GPU，2017 年《Attention Is All You Need》正是去掉 RNN 循环、只保留 attention，故名。

核心知识点

  1. 定位：Transformer 是"集大成者"，复用 embedding / attention / 残差连接 / 归一化 / FFN / Softmax-Linear 等已知组件并重新组合；零基础半小时入门是骗局，但掌握本集 12 个基础概念后，半小时理解 Transformer 不成问题。
  2. 标量/向量/矩阵/张量：逐次升维（标量 → 向量 → 矩阵 → 三维张量 → 四维…），PyTorch 中统一用 tensor 表示；Transformer 中一个 token 是向量、一句话是矩阵、多句话是三维张量（加 batch 维）。
  3. 三种常见运算：①张量加法（形状必须完全相同，逐位置相加，形状不变）②等长向量点积（逐位相乘再累加，结果是标量）③矩阵乘法（(M×P)·(P×N) = M×N，第一个矩阵的行与第二个矩阵的列做点积）。不满足条件时用转置（M×D → D×M）。
  4. Embedding：把离散符号经神经网络训练成低维稠密的语义空间，语义近的词在空间中更近（king − man + woman ≈ queen）。
  5. Encoder-Decoder 与 seq2seq：encoder 负责理解输入序列生成中间隐藏态，decoder 利用它和自己上一步输出预测下一个 token；seq2seq 是该思想的实现，且不要求输入输出等长、不要求位置一一对应。
  6. Attention：让解码器在每个生成时刻重新关注编码器全部隐藏态，按需分配权重，大幅提升长序列性能。
  7. Softmax：把任意一组实数归一化成全正、和为 1 的分布，既可表达注意力权重，也可表达下一个 token 的概率。
  8. 线性变换：本质即线性回归，用可学习权重矩阵对输入做缩放/旋转/组合/升降维；Transformer 用不同的线性变换从同一输入得到 W_Q、W_K、W_V 三个矩阵，进而得到 QKV。
  9. 激活函数：纯线性变换堆叠再多也等价于一次线性变换，必须在两层线性之间加入非线性转折；Transformer 常用 ReLU 或 GELU。
  10. FFN（前馈神经网络，MLP 即典型 FFN）：先升维 → 非线性激活 → 再降维回原维度，为每个 token 提炼更丰富特征。
  11. 残差连接：保留原始信息 + 为反向传播提供更短路径，是深层网络（含 Transformer）可训练的关键，Transformer 内部几乎每个子层连接处都有。
  12. 归一化：让数值稳定；此前 CV 等场景多用 BatchNorm（对一批样本中同一特征维做归一，如"卧室数量"），而 NLP/Transformer 用 LayerNorm（对单个样本自身各特征维做归一，因为不同句子的同位置 token 之间并无共性，同一 token 向量内部各维之间才需要统一尺度）。

第27集 Transformer 第一课：整体架构 BV1eru36jEzL 转写 好

核心知识点

  1. 历史与定位：2017 年 Google《Attention Is All You Need》提出 Transformer，起初仍解决 seq2seq 问题（机器翻译），创新点是 Self-Attention，能处理更长序列并支持 GPU 并行，成为 BERT/GPT/T5 及今日大模型的基础，并外溢到 CV、语音、多模态。
  2. 整体数据流（仍是 Encoder-Decoder）：Inputs → Input Embedding + Positional Encoding 相加 → Encoder 栈（论文默认 N=6 层）产出供 Decoder 读取的表示（即 K、V）→ Decoder 结合 Encoder 表示与已生成的目标前缀产生隐藏表示（即 Q）→ 线性层映射到词表大小得到 logits → Softmax 成概率 → 采样/贪心得下一个 token → 拼回目标前缀循环，直到 <EOS>。
  3. 位置编码的必要性：不再像 RNN 按序推进后，"狗咬人/人咬狗"会变得一样；因此在 Embedding 上加上 Position Encoding 向量再进 Encoder（架构图中该加号有实际含义，非装饰）。
  4. Self-Attention：每个 token 用自己的 Query 去匹配序列中所有 K，得到权重后对 V 加权求和，每个位置的输出都融合了全句信息；各位置互不依赖 → 可整体矩阵化一次算完 → 可并行。公式为 Softmax(Q·Kᵀ/√d_k)·V，√d_k 是保数值稳定的缩放系数。
  5. Multi-Head Attention：用多组不同参数并行地做多次注意力，每个头是一种观察序列的角度（类比 CNN 的多个卷积核各提一类特征），最后拼接融合；只是对注意力的强化，非新机制。
  6. Add & Norm：Add = 残差连接，Norm = LayerNorm（公式 X + F(X) 后再归一化）；因堆叠 N 层后参数量大、原信息易丢失、各层输出分布漂移，故每个子层后都要接一次，纯为训练稳定。Encoder 中每层 2 次、Decoder 中每层 3 次。
  7. FFN：Self-Attention 只决定"关注哪些位置、读多少信息"，还需加工成有表达力的特征——先升维（论文中 512 → 2048）→ 非线性激活 → 再降回原维度（512），输入输出维度不变。Encoder 的核心两部件即 Self-Attention（token 间交换信息）+ FFN（加工成隐藏表示）。

核心知识点

  1. Attention 的定义：为序列中每个 token 生成新的上下文表示的方法——Embedding 后每个向量只含自身语义（+位置），Attention 计算不同位置间的匹配关系，按匹配程度读取并汇总，使每个 token 的向量都融合了全句相关信息。例：it 在 "it was too tired" 中指 animal，改为 "it was too wide" 则指 street，说明词义必须由上下文决定。
  2. 与 seq2seq attention 的异同：两者任务与四步流程相同（理解输入序列 → 理解已生成的输出 → 用当前输出去输入里按需读取 → 融合后预测下一个 token）；差别在于"理解序列"的方式——seq2seq 用 RNN 逐步生成隐藏态，只做一次 attention；Transformer 把"理解"本身也交给 attention，所以要用多次（编码器自注意力、解码器掩码自注意力、交叉注意力）。
  3. 三类注意力的信息来源：编码器自注意力 QKV 全来自自己（看全句、无掩码）；掩码自注意力 QKV 也来自自己，但要遮住未生成的未来部分（防止 Teacher Forcing 下偷看答案造成信息泄露）；交叉注意力 Q 来自解码器（掩码注意力输出的上下文表示），K、V 来自编码器。三者数学形式完全相同，代码里可写成同一个函数传不同 QKV。
  4. Q/K/V 的角色类比：Q 描述"我更新自身时最想查什么"；K 相当于论文的摘要，供别人快速判断是否相关；V 是匹配后要被读取的完整内容。K 与 V 配套来自同一处，是因为"先按摘要算权重、再按权重取内容"。
  5. 计算过程（以 I love deep learning 中 learning 为例）：输入矩阵 X（4×512）分别乘可学习的 W_Q/W_K/W_V 得 Q/K/V → q·Kᵀ 点积得匹配分数 → 除以 √d_k 缩放（否则 Softmax 输入量纲过大、分布过于集中、梯度过小无法训练）→ Softmax 归一化成权重（示例 I 10%、love 20%、deep 45%、learning 25%）→ 按权重对 V 加权求和，得到 learning 的新表示。整句可一次矩阵化并行完成，注意力权重矩阵 A 的第 i 行第 j 列 = 第 i 个位置对第 j 个位置分配的权重。

  7. 编解码流程串讲：Encoder 只编码一次且并行，输出供所有解码步复用（作 K、V）；Decoder 从 BOS 起逐步生成——掩码自注意力得到当前上下文表示作 Q → 交叉注意力用 Encoder 的 K、V → 线性层映射到词表得 logits → Softmax 得概率 → 取"我""喜欢""深度"…直到 EOS。训练时因 Teacher Forcing 有完整答案，这些步可一次性并行，这是 Transformer 远快于 seq2seq 的原因。

核心知识点

  1. 为什么需要位置编码：RNN 靠逐步传递天然带顺序（但慢、串行）；Transformer 把整句组成矩阵一次算出任意两 token 间的关系（快、并行），代价是丢掉了先后顺序——dog bites man 与 man bites dog 的 token 完全相同，不加工就无法区分。因此必须在第一次 Attention 之前补上位置信息。
  2. 实现方式（原论文）：Embedding 向量 + 位置编码向量直接相加（维度相同），合成结果作为输入 X；由于 QKV 都由 X 投影得到，位置信息便暗含在 QKV 中。用加法而非拼接，是为了保持 d_model 维度不变（拼接会翻倍，导致后续所有矩阵运算参数量与计算量上涨），便于与后续模块衔接。
  3. 为什么不能直接用 0、1、2、3… 当位置：Transformer 内部只做点积和矩阵乘法，不做减法，无法像人一样用 6−3 感知距离。也不能用"每位都填位置编号"的常量向量：模式过于单薄，且序列变长后数值（如 3 万）会远超 Embedding 数值范围（0.3、2.1），相加后语义被淹没；归一化则需预设最大长度，不灵活。
  4. 正弦/余弦位置编码：PE(pos, 2i) = sin(pos / 10000^(2i/d_model))，PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))。d_model=512 时 512 维两两分组共 256 组，i 为组号；分母 10000^(2i/d) 随 i 增大而增大（1、10、100…），即不同维度以不同频率变化——靠前的维度变化快（能区分相邻位置但远处会周期重复），靠后的维度变化慢（近处几乎相同、远处才有差别）。

  2. Encoder 的两大核心部件 + 两个稳定件：多头自注意力（token 间互相交换信息）→ Add & Norm → FFN（对 token 自身做加工、提炼特征）→ Add & Norm；架构图 N× 表示堆叠，论文为 6 层，每层有独立的 Attention 与 FFN 参数。

  5. 层归一化：对每个 token 向量的 512 个特征维度横向做归一化（不跨 token 交换信息），使层间数值分布稳定；顺序上原论文为 Post-Norm（先 Add 后 Norm），现代大模型普遍改 Pre-Norm（先 Norm 再进子层再 Add），深层训练更稳定（本集代码仍按原论文 Post-Norm 实现）。

核心知识点

  1. 编码器输出：整个源序列一次并行处理完，得到 H（S×d_model），供解码器反复参考；解码器推理时则从 BOS 起逐 token 生成（打字机效果），每生成一个 token 矩阵就多一行，最终为 T×d_model（S 与 T 不必相等，列数 d_model 恒定）。
  2. Decoder 三大部件的差异化：Embedding、位置编码、Add & Norm、FFN 与编码器完全相同可复用；最大区别是两个注意力——掩码多头自注意力（Masked Multi-Head Attention）+ 多头交叉注意力（Cross-Attention），外加最后的线性层 + Softmax。
  3. 掩码自注意力：本质仍是自注意力（QKV 全部来自已生成序列自己），区别只在训练时把"未来位置"遮住——因为 Teacher Forcing 一次给了完整答案，不遮就会直接看到答案（信息泄露/作弊）。实现上在 Q·Kᵀ 分数矩阵上加 −∞ 掩码（Softmax(−∞)=0，权重即置零），只保留下三角；推理时本来就没有未来 token，但为与训练保持一致仍保留该结构。
  4. 交叉注意力：Q 来自 Decoder（掩码注意力 + Add & Norm 后的表示 Z_t，即"我已经翻译到哪了、想查什么"），K、V 来自 Encoder 的 H 经 Decoder 自己的 W_K/W_V 投影得到（K 如摘要、V 如全文）。计算逻辑与自注意力完全一致，只是 QKV 来源不同——故代码里三种注意力可复用同一个函数。
  5. 为什么预测只取"最新一行"：掩码自注意力之后，最新 token 的向量已融合整个已生成序列的信息，再经交叉注意力参考原文，就足以预测下一个 token；训练时则把整个矩阵一次送进去并行算完（Teacher Forcing），训练一次完成、推理要跑 T 次。
  6. 输出头：FFN（512→2048→512 升维再降维）→ 线性层把 d_model 维向量映射到词表大小（如 10 万维）得到 logits（未归一化的打分，不是概率、不是权重）→ Softmax 转成和为 1 的概率分布。
  7. 解码策略三件套：temperature（调 logits 尺度，值越小分布越尖锐/确定性强，编程场景常设 0；越大越平缓、多样性高，适合故事生成）top-k（只保留概率最高的 k 个，其余置零）top-p（按概率从高到低累加到 p 如 0.85 为止，候选数动态）；三者可组合：先用 temperature 调分布，再用 top-k/top-p 缩候选，最后采样或取最大（贪心）。Softmax 只负责给出分布，具体选谁是解码策略的事。
  8. 训练 vs 推理对照：训练——整句已知、一次矩阵运算、T×T 分数矩阵加因果掩码、输出一次全拿到、步数 1；推理——每步只知道前缀、只算最新一个 Q（1×d_model）、从 KV Cache 取历史 KV 并 append 自己的 KV、每步一次预测、步数 = 目标 token 数。
  9. Batch 与 Padding：实际训练再加一维 B（batch） 组成三维张量；同批句子长度不一，用 padding 补齐到最长，并额外加 Padding 掩码把 PAD 位置权重置零（区别于因果掩码——因果掩码防偷看未来，Padding 掩码让填充位不参与运算）。
  10. Decoder 一句话总结：用掩码自注意力理解已生成内容 → 用交叉注意力融合编码器（原文）信息 → FFN 提纯 → 多层堆叠（shape 不变，靠残差+归一化防梯度消失/参数爆炸）→ 线性层映射词表得 logits → Softmax 得概率 → 按策略选 token → 拼回序列继续，直到生成 EOS。

第34集 为什么是 Decoder-Only 的 GPT 赢了 BV16yhd6BEdf 转写 好

核心知识点

  1. 三条分支：Transformer（2017）原为机器翻译设计，之后衍生出三个架构——GPT（decoder-only）：只用解码器，无编码器故也无交叉注意力，比原版 decoder 更简单；BERT（encoder-only）：只用编码器，双向；T5（encoder-decoder）：与原始 Transformer 最接近。
  2. 共同贡献——预训练+微调范式：此前每个任务都从 0 到 1 单独训练（分类找分类标注、问答找问答标注）；GPT/BERT 先在海量无标注互联网文本上自监督预训练，学会词法、语法、语义与句间关系，再用少量标注数据配一个任务头做微调（参数调整量相对预训练极少），即可得到分类/问答等模型。
  3. GPT-1（2018.6，OpenAI，晚于 Transformer 约一年）：两阶段——无标注文本上不断预测下一个 token 做预训练（只用左侧上下文，因果自注意力），再有标注任务数据上微调，迁移到文本分类、问答、自然语言推断；率先提出"先学通用语言规律、再迁移到具体任务"的范式。
  4. BERT（Google，晚 GPT-1 几个月）：既然训练时左右文本都知道，就同时利用左右两侧预测被遮住的词——随机选约 15% 的 token 做遮挡（MLM），其中 80% 替换为 [MASK]、10% 换成随机词、10% 保持不变（防止模型依赖 mask 这个字符）。核心贡献：证明同一个预训练 encoder 一次预训练即可作为多种理解类任务（分类、实体识别、阅读理解）的共同底座，只需换不同任务头微调；当时在各类评测榜遥遥领先，极大推广了预训练+微调范式。局限：双向编码不擅长开放式生成。
  5. T5（2019，Google，完整 encoder-decoder）：最大贡献是把分类、翻译、摘要、问答等所有 NLP 任务统一成"文本进、文本出"——在输入前加任务前缀（如 `translate English to German: ...`）即可；相比 BERT 仍需为每个任务设计不同任务头与不同数据格式，T5 统一了训练方式与数据格式（但不同任务仍要各自微调）。此外论文做了大规模消融实验，并清洗构建了大语料库 C4，至今仍被广泛使用。这一"用输入文本表达任务"的思路直接影响了 prompt engineering 与指令微调。
  6. GPT-2：坚持 decoder-only + 因果自注意力自回归生成，不做任何任务微调，靠上下文（提示）告诉模型做什么，即零样本任务迁移（摘要写 "TL;DR:"、翻译写 "ENGLISH: … FRENCH:"、问答写 "Q: … A:"）。两个关键选择：坚持 decoder-only；继续扩大规模（参数 1.5B，约 BERT 最大模型的 4.4 倍）。当时效果一般，不如 T5。
  7. *Scaling Law（2020，OpenAI）**：系统研究参数量、数据量、训练时长与损失的关系——当其他条件不构成瓶颈时，任意增加其中一项，损失都会按稳定的幂律趋势下降，不会轻易过拟合。意义在于给了投资人与企业家确定性（加钱就有确定收益、还能预估收益量），直接催生 GPT-3。
  8. GPT-3（175B）：延续零样本路线，并系统对比 zero-shot / one-shot / few-shot（均不更新参数），展示了上下文学习（In-Context Learning）——模型从上下文的示例里识别任务模式与输出格式。与微调对比：微调把适配能力写进参数（切换任务需重新训练、成本高）；上下文学习把适配放进输入（切任务只改描述与示例，成本低、可快速验证）。这正是 prompt engineering 的由来（2024 年底—2025 年甚至出现"提示词工程师"岗位）。
  9. 2022 年底基于 GPT-3.5 的 ChatGPT 让自然语言成为调用模型能力的入口；今天 Agent 开发中的 context engineering（上下文工程） 也是同一思路的延伸（把工具、历史、错误反馈放进上下文再让模型决定下一步）。
  10. Decoder-only 胜出的四个原因：①训练样本极易构造——任意连续文本右移一位即得 teacher forcing 标签，N 个 token 产出 N−1 个训练信号；BERT/T5 是"填空式"预训练目标，不擅长开放式生成，且训练目标与生成目标不一致 ②用上下文切换任务，不需微调、不需换任务头，规模变大后描述与 few-shot 就能识别任务 ③结构最简单便于扩展：无编码器、无交叉注意力，省下的参数可堆更多层，KV Cache 与缓存管理策略也更容易复用（工程红利）④训练目标统一（永远只是预测下一个 token）+ 任务表达统一 + 结构统一，与 Scaling Law 相互促进。今天 LLaMA、通义千问、DeepSeek、Kimi、GLM 等主流模型基本都是 decoder-only。
  11. 观念转变：能力不再全部写进参数，而是可以通过输入激发，即所谓能力涌现；模型在预训练中积累能力，通过上下文切换完成不同任务。

第35集 一小时手搓现代 GPT，学会写古诗 BV1x6a364Efb 转写 好

核心知识点

  1. GPT = decoder-only：只用 Transformer 右侧解码器，因无编码器输入，故没有交叉注意力，只需（掩码）多头自注意力 + FFN，反复堆叠 N× 个 GPT block，最后线性层映射词表得 logits → Softmax → 按策略选 token → 追加回前缀循环，直到 EOS 或最大长度。会手写 Transformer 就能手写 GPT（删掉编码器与交叉注意力即可）。
  2. 本集加入的五项现代大模型改进：①RoPE 旋转位置编码取代输入端的绝对位置编码（位置信息不再与语义相加，而是在算注意力时旋转 Q、K）②Pre-Norm 取代 Post-Norm（先归一化再进子层，深层训练更稳定）③RMS Norm 取代 Layer Norm（不再减均值、只除以均方根并乘可学习系数 γ，减少运算）④SwiGLU 取代 ReLU 的 FFN（门控双分支）⑤线性投影去掉偏置 bias（归一化已能处理偏置，减少冗余参数）。
  3. RoPE 细节：只对 Q 和 K 旋转、不对 V 旋转（注意力权重由 Q·K 点积决定，旋转后点积含两位置的角度差即相对位置；V 只是按权重被取值，旋转它会污染内容且无收益）。旋转方式：把每头维度（本例 96/6=16）按奇偶两两配对（8 对），第 i 对在位置 pos 的旋转角 α = pos × θ_i，θ_i = base^(−2i/head_dim)（base=10000）；用 sin/cos 旋转矩阵实现，sin/cos 表预算好后存入 register_buffer（不参与梯度）。好处：语义是语义、位置是位置，两者解耦；只旋转 Q/K，运算量也小。
  4. 数据与分词：用开源中华古诗词数据集（Chinese Poem），筛出四句五言且转简体、按正文去重；低频字（出现少于 5 次）统一替换为 `<UNK>` 以缩小词表、便于训练；构建 token↔id 双向映射，特殊字符 BOS / EOS / `<UNK>`。最终词表约 3502，每首诗正文 20 字 + 4 个标点 = 24 字符，加 BOS/EOS 后长度 26（训练输入去掉尾部 EOS，标签去掉头部 BOS，错位一位即 teacher forcing）。
  5. 超参数：d_model = 96、heads = 6（每头 head_dim = 16）、d_ff = 256、GPT block 堆叠 4 层、max_length = 32、RoPE base = 10000、Dropout < 10%；环境 Python 3.12 + PyTorch + matplotlib（UV 管理并锁定版本），可用 CUDA / MPS / CPU。
  6. 关键实现要点：Embedding 用 `nn.Embedding(vocab, d_model)`，初始化标准差设 0.02（避免初始值过大）并接 `nn.Dropout`；多头时为提速把 QKV 用一次线性投影到 3×d_model 再切分（bias=False）；维度变换 B,L,d_model → reshape → (B, L, h, d_h) → transpose 成 (B, h, L, d_h) → 对 Q/K 做 RoPE → attention → transpose 回来 → contiguous → reshape 回 d_model → 再经 W_O 融合；score = Q·Kᵀ/√d_h，用右上三角 −∞ 掩码实现因果掩码（Softmax(−∞)=0）。
  7. SwiGLU FFN：up 分支做线性升维（d_model→d_ff）、gate 分支做线性升维后过 SwiGLU 激活，两者按位相乘，再由 down 分支降回 d_model；相当于"信息分支 + 门控分支"，比 ReLU（负值被截断、单通路）保留更多信息、理解更充分。
  8. RMS Norm 实现：`x / sqrt(mean(x²) + ε) * γ`，γ 为可学习的 `nn.Parameter`（初始化全 1），ε 防除零。
  9. GPT block 连接（Pre-Norm）：x → RMS Norm → 多头自注意力 → Dropout → 残差相加 → RMS Norm → SwiGLU FFN → Dropout → 残差相加；N 层堆叠后，最后再补一次 RMS Norm 再输出。
  10. 输出头与权重共享：96 维隐藏表示经线性层投影到词表大小（3502）得 logits（训练时不手动 Softmax，交给交叉熵损失；采样时再处理）；因为输入输出是同一套中文词表，输出投影层可复用 Embedding 参数表省参数（而 mini Transformer 英译中因词表不同不能共享）。
  11. 训练：自监督（右移一位作标签）+ 因果掩码 + Teacher Forcing；批量训练（一次把整首诗的矩阵送进去，与上集 mini Transformer 的逐句循环不同）；防过拟合组合拳——Dropout、AdamW（含 weight decay）、Early Stopping、Label Smoothing（评估时不启用 Label Smoothing 与 Dropout，切 `model.eval()` 并 `no_grad`）。实际结果：损失从 5.3 降到 4.6267，第 18 轮已最优、第 28 轮早停（最多设 1000 轮）；d_model 从 64 提到 96 后效果明显改善。
  12. 推理/采样：从 BOS（+可选首字 prompt）起逐步生成；策略用 top-k（只在前 k 个候选中采样）、temperature（调分布随机性）、并加重复惩罚（与前一个字相同则人工降权，减少连续重复）；遇到 EOS 或达到 max_length 停止。示例：不给提示生成"春雨不入谷，花音难入门"；给首字"春"/"月"即按该字开头，格式工整（四句五言、标点位置正确），虽平仄押韵一般，属"赛博诗人"。本例未使用 KV Cache，每追加一个字符都重算全部（诗短，开销可接受）。

第36集 深度学习课程内容串联 & 学习路径总结 BV1dhp56oERL 转写 中

核心知识点

  1. 课程主线串联：基础概念与训练关键（激活函数、损失函数、反向传播、梯度下降与优化器）→ 训练稳定性与泛化技巧（学习率调度、参数初始化、归一化、正则化）→ CNN（CV）→ NLP（文本表示 → RNN → LSTM/GRU → seq2seq → 注意力）→ Transformer（自注意力、并行原理、编解码器协作、BERT/T5/GPT 三大实现、预训练/指令微调/偏好优化）→ 学习路径建议。核心观点：不要上来就学 Transformer，前面每块都是它的前置。
  2. 深度学习 vs 机器学习：深度学习是机器学习的分支，都追求对新数据的泛化；区别在于机器学习用人工设计的、人能理解的结构化特征（表格数据），深度学习把特征提取也交给模型一起训练，因而能处理图像/音视频/文本等非结构化数据，代价是网络多层、结构复杂、训练成本高。
  3. 训练四步闭环：前向传播 → 与真实标签比对用损失函数算误差 → 按链式法则反向传播（把误差责任分到每一层，PyTorch 自动完成）→ 梯度下降沿负梯度更新参数 → 循环至收敛。激活函数（ReLU / sigmoid / tanh / GELU / SwiGLU，给网络注入非线性，否则多层线性叠加等价一层）损失函数（回归用均方差、分类用交叉熵）反向传播（只算梯度不更新参数）梯度下降与优化器（SGD / mini-batch SGD → 动量 → 自适应学习率 AdaGrad/RMSProp → Adam → AdamW，后者修正了 Adam 中权重衰减未从梯度更新中独立出来的问题）。
  4. 稳定性三件套：学习率调度（阶梯递减 step decay、余弦退火、配合 Warm up 先升温再退火，类比跑步先热身再提速最后减速）参数初始化（不能全同值→对称性问题；尺度太小→梯度消失、太大→梯度爆炸；sigmoid/tanh 用 Xavier，ReLU/Leaky ReLU/SELU 用 Kaiming/He 初始化（何凯明），偏置通常置 0）归一化（BatchNorm 用于图像、LayerNorm 用于 NLP，每层操作后都跟一次，解决特征分布差异过大）。
  5. 防过拟合：L1（惩罚绝对值，鼓励稀疏、筛选特征，机器学习常用）L2（惩罚平方，抑制大权重但不置零，深度学习更常用）权重衰减（更新时给权重乘衰减系数，像加弹簧）Dropout（随机关闭神经元，防止依赖特定特征组合）Early Stopping（验证集连续 N 轮无改善即停）。
  6. CNN 适用图像的三条先验：局部性（相邻像素相关性更大）、参数共享（同一卷积核全图扫描）、平移等变性（左右上下翻转仍是同一物体）+ 层次组合；流程为 卷积 → 非线性激活 → 池化下采样 → 残差块堆叠多层 → 全局平均池化 → 全连接分类；浅层学边缘方向、中层学纹理局部、深层学"眼睛/耳朵"等语义。
  7. NLP 演进复习：one-hot（高维稀疏、正交无语义）→ Embedding/word2vec（分布式假设，把离散 token id 映射为可训练稠密向量，语义相近则距离近）→ RNN（隐藏态逐 token 传递，参数共享、可处理不定长，但串行、长程遗忘）→ LSTM/GRU（门控选择性记忆/遗忘，缓解不根治）→ seq2seq（编码器出上下文向量、解码器自回归生成，解决输入输出不等长）→ 注意力（解码每步对编码器全部隐藏态算分数→Softmax→加权求和，得到动态上下文）→ Transformer 自注意力（每个位置访问全部位置、可并行、加因果掩码）。
  8. Transformer 架构复习：输入 Embedding + 位置编码相加 → 编码器堆叠（自注意力 → 残差+归一化 → FFN；输出维度不变，作为 K、V）→ 解码器堆叠（掩码自注意力 → 交叉注意力：Q 来自解码器、KV 来自编码器 → FFN）→ 线性层映射词表得 logits → Softmax 得概率 → 逐 token 生成至 EOS。
  9. 三大实现：BERT（Encoder-only，双向编码，擅长表示学习与分类、不擅长生成）GPT（Decoder-only，自回归逐词生成，适合续写与对话）T5（标准 encoder-decoder，把任务统一为 text-to-text）；BERT 与 GPT 开启预训练时代。
  10. 大模型训练三阶段：预训练（大规模语料学通用知识与语言规律，产出基座模型）→ 指令微调 / SFT（问答、总结、翻译、代码等有标注数据上微调，学会遵从指令与格式，产出指令模型）→ 后训练 / 偏好对齐（RLHF、DPO，对齐人类偏好、安全规则与拒答行为，使模型更好用、更安全、更稳定）。

6. 读后自测 10 题

Q1. 为什么单层感知机无法解决异或问题？多层网络为什么可以？
答：异或不是线性可分的——找不到一条直线把两类分开，而单层感知机的决策边界就是一条直线（线性模型）。多层网络通过隐藏层把输入变换到新的空间，再叠加非线性激活函数，就能构造出非线性决策边界，从而解决异或。
Q2. 激活函数的作用是什么？没有它会怎样？
答：作用是注入非线性。如果没有激活函数，无论堆多少层，最终都等价于一个线性变换（矩阵连乘仍是矩阵），网络表达能力退化为单层线性模型，无法拟合复杂模式。
Q3. 反向传播和梯度下降是一回事吗？
答：不是。反向传播是一种高效计算梯度的算法（利用链式法则从输出层往回逐层算偏导）；梯度下降是利用这些梯度去更新参数的学习算法。前者负责「算」，后者负责「走」。
Q4. BatchNorm 和 LayerNorm 的区别？Transformer 为什么用 LayerNorm？
答：BatchNorm 在一个 batch 内跨样本、对每个特征做归一化；LayerNorm 对单个样本、跨特征做归一化。Transformer 处理变长序列，batch 内样本长度不一且 NLP 任务 batch 统计不稳定，LayerNorm 不依赖 batch 统计量，训练更稳定，因此成为标准选择。
Q5. 注意力机制里 Q、K、V 分别扮演什么角色？为什么要除以 √d_k？
答：Query 是当前位置发出的「查询」，Key 是所有位置提供的「被匹配标识」，Value 是实际要取出的「内容」。用 Q·K^T 算相似度、softmax 归一化后对 V 加权求和。除以 √d_k 是因为维度越大点积的方差越大，会把 softmax 推到梯度极小的饱和区，缩放后能保持梯度健康。
Q6. Multi-Head Attention 为什么要分成多个头？
答：单个注意力只能在一个表示子空间里做加权平均；分成多个头，每个头在不同的投影子空间中并行关注不同方面的信息（如一个头关注语法依赖、另一个关注语义指代），最后拼接起来，模型的表达能力更强。
Q7. 为什么现代大模型主流是 Decoder-Only 架构？
答：Decoder-Only 用自回归（预测下一个 token）统一了理解与生成：预训练任务极其简单（就是续写），数据规模可以无限扩大，且推理时天然支持少样本提示（把任务描述当上下文续写即可）。相比之下 Encoder-Decoder 的训练目标更复杂、 scaling 效率更低。
Q8. 残差连接解决了什么问题？为什么 Transformer 也要用它？
答：残差连接给梯度提供了一条从深层直达浅层的「捷径」，缓解深层网络的梯度消失/退化问题，使训练上百层成为可能。Transformer 堆叠多层注意力和前馈网络，同样面临深度带来的训练困难，因此每个子层都加了残差连接 + LayerNorm。
Q9. 从机器学习课的「梯度下降」到本课，它发生了什么变化？
答：核心思想不变（沿负梯度更新），但规模和工程细节大幅升级：参数量从几个涨到数十亿，优化器从朴素 SGD 演进到 Adam/AdamW（带动量与自适应学习率、解耦权重衰减），并配合学习率调度、梯度裁剪、混合精度等工程手段。
Q10. 为什么说 Transformer 是「金丹」，而不是终点？
答：因为修仙路线的目标是 AI 安全：Transformer 只是让你理解「注意力能被劫持」的原理（金丹），真正的元婴期要把大模型拆开看——分词、嵌入、位置编码、解码策略、对齐与 RLHF——每一处都是可能的攻击面。理解架构只是入场券。
