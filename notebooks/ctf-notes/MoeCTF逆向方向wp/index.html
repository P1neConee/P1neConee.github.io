搜一下特征

Base58 特征

  1. 字母表固定
    123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz
    共 58 个字符。
  2. 去掉了易混淆字符
    没有 0、O、I、l，也没有 +、/、=。
  3. 前导 1 表示前导零字节
    解码时，开头的每个 1 对应一个 0x00 字节。
  4. 本质是大整数进制转换
    把字节串当成大整数，按 58 进制编码/解码：
    num = num * 58 + index
  5. 无填充，长度可变
    不像 Base64 有 = 补位。
  6. 常见用途
    比特币地址、IPFS、Ripple、CTF 逆向题中的隐藏编码。
  7. 代码识别特征
    • 出现那串 58 字符常量
    • strchr 查字母表
    • 循环里乘 58
    • 大整数数组（常见 128 字节）
    • 统计前导 '1' 数量
  8. 与 Base64 区别
    • Base64：有 + / =，含 0OIl
    • Base58：无符号，无易混淆字符，纯字母数字
  9. CyberChef 解法
    搜索 From Base58，输入字符串即可解码。

问题2：strtoul()函数含义是什么，有何作用？

答：string to unsigned long（字符串转无符号长整型），把字符串里开头的数字抠出来，变成整数。一碰到其他字符就退出，如果没有值的话返回0

作用：判断有无数值，这里用来判断是否有调试进程，有就返回真值，用来反调试

往后走，三个函数

build_required_token(s)，acquire_operator_token()，compare_operator_token(v8, s)

第一个build_required_token(s)

问题1：看到类型提示想改参数类型，改成int *a1报错了

答：要改成char *a1

具体不知道为啥

因为反编译里 *(_BYTE *)(a1 + i) = ... 的意思是：a1 是一个地址，往 a1 + i 这个字节位置写数据。如果你把它改成 __int64 *a1，那 a1 + i 就变成“跳过 i 个 int64”了，语义完全变了。这里的 a1 应该理解为 char \*a1（字符串首地址），反编译工具偷懒没给你标清楚类型而已。

第二个acquire_operator_token()

问题：&按位与作用

答：

  • 奇数的最低位是 1 → getpid() & 1 == 1
  • 偶数的最低位是 0 → getpid() & 1 == 0

作用：判断奇偶

第三个就是简单比较数据，使v8和s相等

然后进行自揭密程序self_driven_decrypt(v7, v6, v4)

然后程序结束

然而写解密时还要注意加密了谁，加密用的数据是已经加密过的还是没有加密过的。还原的时候怎么用值

加密时 v[0] 先更新，然后 v[1] 用新的 v[0] 算 MX。
所以解密时，v[15] 要先还原，并且它用的 y 是“还没还原的 v[0]”；
还原完 v[15] 后，v[14] 用的 y 正好是刚还原的 v[15]。
这就是 y 从头传递到尾的“接力”。

这其实是XXTEA算法的改版，只要认出它以后就好办了

XXTEA特征

最外层：轮循环（for r = 0..rounds）
中间层：字循环（for p = 0..n-1）
最内层：一个 MX 函数（用左右邻居 + sum + key 算一个值）
